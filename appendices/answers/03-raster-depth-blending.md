# 第 03 章理解检查参考答案

[返回第 03 章](../../chapters/03-raster-depth-blending.md) · [返回目录](../../README.md)

> 本页都是图形学推理和教学输入的计算结果，不是 UE 项目运行测量。使用 UE 5.7.4、配置 A 的实现结论时，仍需遵守正文列出的状态分支与证据边界。

## 题 1：共享边归属

`(2.5,2.5)` 满足共同边 BC 的方程 `x+y=5`，所以位于两个三角形的共享对角线上。

在 `ABC` 中，该边方向是 `B→C`，`dy=4>0`，按正文坐标与绕序约定不接受等号；在 `BDC` 中，该边方向是 `C→B`，`dy=-4<0`，接受等号。因此样本归 `BDC`。

两边都使用 `>=0` 会把该样本判给两个三角形。对于透明混合，这可能成为不必要的两次贡献。两边都用严格 `>0` 又会共同排除边界，因而需要一致的边归属规则。这个结论假设两三角形共享完全一致的边位置；规则不会修复真实几何裂缝。

## 题 2：透视正确插值

位置 `X=(2.5,1.5)` 与顶点屏幕分量都以像素间距为单位。仍有 `D=E_AB(C)=16`，三个对边面积量分别为：

```text
E_BC(X)=4
E_CA(X)=8
E_AB(X)=4

λA=1/4, λB=1/2, λC=1/4
```

权重无单位。直接按屏幕权重组合 UV，得到：

```text
UV_linear = (1/4)(0,0) + (1/2)(1,0) + (1/4)(0,1)
          = (0.5,0.25)
```

根据 `wA=1`、`wB=2`、`wC=4` 修正：

```text
H  = (1/4)/1 + (1/2)/2 + (1/4)/4
   = 1/4 + 1/4 + 1/16 = 9/16

NU = (1/2)×1/2 = 1/4
NV = (1/4)×1/4 = 1/16

U = NU/H = 4/9 ≈ 0.444444
V = NV/H = 1/9 ≈ 0.111111
```

`H` 是齐次权重分母，`NU`、`NV` 是两个分量的分子，最终 UV 无单位。透视信息来自各顶点不同的 `w`，不是来自边函数本身。若三者 `w` 相同，修正就会约掉，结果退回屏幕线性插值。

## 题 3：测试深度，但不写入

这里所有数字都是同一约定下的无量纲设备深度。第一片满足 `0.8>=0.65`，通过；由于不写深度，缓冲仍是 `0.65`。第二片也满足 `0.7>=0.65`，通过。两片都在不透明底层前方，应该进一步根据层次和颜色模型合成。

若第一片写入 0.8，第二片将因 `0.7<0.8` 失败。然而第一片是半透明的，它后面的第二片仍可能应通过剩余透射权重影响颜色。简单让最近透明层占据普通深度，会丢掉必要的后方透明贡献。

“不写深度”也不自动解决排序；两片都通过之后，普通 source-over 混合仍通常需要后到前的正确顺序。本文讨论的是该普通模型，其他透明算法可能采用额外列表、多层资源或不同合成策略。

## 题 4：两种颜色表示与一次错误匹配

RGB 为统一线性相对光量，Alpha 为无单位权重。非预乘表示直接计算：

```text
C_out = 0.25(0.2,0.4,1.0) + 0.75(0.8,0.2,0.0)
      = (0.05,0.10,0.25) + (0.60,0.15,0.0)
      = (0.65,0.25,0.25)
```

预乘源是 `C'_src=(0.05,0.10,0.25)`，使用源因子 1：

```text
C_out = C'_src + 0.75 C_dst = (0.65,0.25,0.25)
```

若预乘源又乘了源 Alpha：

```text
C_wrong = 0.25(0.05,0.10,0.25) + 0.75(0.8,0.2,0.0)
        = (0.6125,0.175,0.0625)
```

源贡献多乘了一次 0.25，尤其蓝通道变暗。若 Alpha 保存剩余背景权重，原值为 1，则新值为 `(1-0.25)×1=0.75`。它不是通用 source-over 覆盖 Alpha；后者若背景已不透明，输出覆盖 Alpha 仍为 1。

## 题 5：分清计数与证据

12 是三角形数，不是像素 Shader 调用次数。一个三角形可以覆盖成千上万个屏幕样本，图元边缘还可能需要辅助调用。方块可能参与多个 Pass 和视图，最终看见的像素数也不等于其全部着色执行数。

Opacity 为 0 只说明特定混合模型下没有该源颜色的正常贡献，不证明绘制命令、顶点处理、覆盖和材质计算全部消失。是否存在可提前消除的常量条件，应根据实际编译和执行路径判断。

深度预通道增加几何与深度工作，其收益来自后续减少的重复着色等开销。材质很轻、遮挡很少时，这笔额外成本未必值得。不能根据开关名字直接保证帧时间降低。

可补充的运行证据包括：同硬件、分辨率和稳定场景下，开关前后的 GPU 各 Pass 时间及总帧时间；所选绘制的深度／混合状态与绑定资源；CPU 绘制组织成本；相关覆盖或像素执行计数。至少提供其中两项，并说明工具统计的单位与范围。Shader Complexity 的颜色和单次任务管理器 GPU 百分比都不能独立替代这些证据。
